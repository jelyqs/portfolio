# auth.md — Authentication for thunguyenit.com

This site is a public portfolio. **No authentication is required for anything on this site.**

- There is no login, no user account, no protected resource, and no API key.
- Every discovery endpoint below is public and returns data without any credentials.
- There is no OAuth, OIDC, or token endpoint on this site (none is published because none exists).
- The MCP server at `/mcp` is public, read-only, and stateless: no session, no API key, no auth header.
